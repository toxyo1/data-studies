# 01 — Fundamentos : O que é SQL?
SQL (Structured Query Language, ou Linguagem de Consulta Estruturada) é a linguagem padrão usada para se comunicar com bancos de dados relacionais. Diferente de linguagens de programação como python ou javascript, o SQL é uma linguagem declarativa: você descreve o que quer obter, e não como obter. Algumas caracteristicas do SQL:
- Criada nos anos 1970, é usada até hoje por praticamente todos os bancos de dados relacionais do mercado (MySQL, PostgreSQL, SQL Server, Oracle, SQLite etc).
- Serve tanto para consultar dados quanto para criar, alterar e remover estruturas, manipular registros e controlar permissões de acesso.
- É uma linguagem com sintaxe muito próxima do inglês, o que facilita a leitura mesmo para quem está começando.

## Para que serve o SQL na prática?
- Consultar informações armazenadas em tabelas (ex: listar todos os clientes de um e-commerce).
- Inserir, atualizar e remover dados (ex: cadastrar um novo pedido, corrigir um endereço, excluir um usuário).
- Criar e modificar a estrutura do banco de dados (tabelas, colunas, relacionamentos).
- Controlar quem pode acessar ou modificar os dados.
- Garantir consistência e integridade das informações através de regras e transações.

## O que é uma tabela?
Uma tabela é a estrutura usada para armazenar dados dentro de um banco relacional.
exemplo de uma tabela chamada `clientes`:

| id | nome   | idade |
|----|--------|-------|
| 1  | Marian | 26    |
| 2  | João   | 30    |

- Cada linha representa um registro (nesse caso, um cliente).
- Cada coluna representa uma característica desse registro (nome, idade etc).
- O `id` costuma ser um identificador único de cada linha — esse conceito de chave será aprofundado mais adiante, no capítulo de chaves primárias.

## Classificação dos comandos SQL
Os comandos SQL são divididos em quatro grandes grupos, de acordo com sua finalidade. Todo comando SQL pertence a uma dessas categorias. São eles:
- DDL (data definition language): comandos que definem ou alteram a estrutura do banco de dados. ex: `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.
- DML (data manipulation language): comandos que manipulam os dados dentro das tabelas. ex: `SELECT`, `INSERT`, `UPDATE`, `DELETE`. (Alguns autores tratam o `SELECT` separadamente, numa categoria chamada DQL — data query language. Não é um erro encontrar essa divisão em outros materiais.)
- DCL (data control language): comandos que controlam permissões de acesso ao banco. ex: `GRANT`, `REVOKE`.
- TCL (transaction control language): comandos que controlam transações, garantindo que operações aconteçam de forma segura. ex: `COMMIT`, `ROLLBACK`, `SAVEPOINT`.

## Bancos de dados relacionais — conceito rápido
Um banco de dados relacional organiza as informações em várias tabelas que podem se conectar entre si através de chaves, permitindo cruzar informações (isso será aprofundado no capítulo de modelagem de dados). Pense nele como um conjunto de planilhas relacionadas, em vez de uma única planilha solta.

* Exemplo prático - Imagine a tabela `pedidos`, com as colunas `id`, `cliente`, `valor` e `status`. Uma consulta simples para listar apenas os pedidos com status "concluído" seria:
SELECT *
FROM pedidos
WHERE status = 'concluido';

## Principais SGBDs do mercado
SGBD significa Sistema Gerenciador de Banco de Dados — é o software que implementa o SQL e gerencia os dados de fato. O padrão SQL é seguido por todos eles, mas cada SGBD tem pequenas particularidades de sintaxe. Os mais usados atualmente são:
- MySQL: muito usado em aplicações web, código aberto.
- PostgreSQL: código aberto, robusto, com muitos recursos avançados.
- SQL Server: da Microsoft, comum em ambientes corporativos.
- SQLite: leve, roda localmente sem servidor; muito usado para estudos e em apps mobile.
- Oracle Database: usado principalmente em grandes corporações.
