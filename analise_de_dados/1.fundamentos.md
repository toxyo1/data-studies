# 01 — O que são dados?
Dados são registros brutos de fatos, observações ou medições, ainda sem interpretação. Por si só, um dado não responde nada: o valor "1200", a palavra "Recife" ou a data "07/09/2026" são dados, mas só ganham sentido quando alguém sabe a que se referem.

No dia a dia, dados são gerados o tempo todo: uma compra em uma loja, um clique em um aplicativo, a leitura de um sensor, o preenchimento de um formulário. Cada uma dessas ações deixa um registro, e a soma desses registros é a matéria-prima do trabalho com dados.

> Os dados podem ter formatos diferentes (números, textos, datas, imagens, áudio). Esse assunto será detalhado mais adiante, no módulo de exploração dos dados.

## A área de dados
A área de dados reúne os profissionais e processos responsáveis por transformar dados brutos em algo útil para uma organização — seja um relatório, um modelo preditivo ou uma recomendação de ação. Nas últimas décadas, essa área cresceu muito porque as empresas passaram a gerar e armazenar uma quantidade enorme de dados (vendas, comportamento de clientes, operações, marketing etc.), e saber extrair valor desses dados virou um diferencial competitivo.

De forma simplificada, podemos pensar em três grandes frentes de trabalho que se complementam (essa é uma visão didática, dependendo da organização podem existir outras frentes especializadas)

- Engenharia de Dados: cuida da infraestrutura: coleta, armazenamento, organização e disponibilização dos dados para que outras pessoas possam usá-los. É quem constrói os "canos" por onde os dados passam.
- Análise de Dados: foca em interpretar dados já organizados, respondendo perguntas de negócio e gerando relatórios, dashboards e insights para apoiar decisões.
- Ciência de Dados: usa estatística avançada e aprendizado de máquina para construir modelos preditivos e resolver problemas mais complexos, podendo trabalhar tanto com dados estruturados quanto com dados não estruturados (texto, imagem, áudio), dependendo do problema.

Essas três frentes trabalham em conjunto: o engenheiro de dados prepara e disponibiliza os dados, o analista os transforma em informação e insights práticos, e o cientista de dados constrói modelos mais sofisticados quando o problema exige.

## Como a área de dados contribui para uma organização
- Reduz decisões baseadas apenas em "intuição" ou "experiência";
- Ajuda a identificar problemas e oportunidades que não seriam percebidos a olho nu;
- Permite medir o impacto real de ações e estratégias (uma campanha funcionou? um produto está performando bem?);
- Cria uma cultura de melhoria contínua baseada em fatos, não apenas em suposições.

## O que é análise de dados
Análise de dados é o processo de investigar, interpretar e extrair sentido de um conjunto de dados, com o objetivo de responder perguntas, entender situações e apoiar decisões.

Alguns pontos-chave dessa definição:
- Investigar: analisar não é simplesmente "olhar os dados", é fazer perguntas sobre eles e buscar respostas com método.
- Interpretar: números e gráficos sozinhos não significam nada — é preciso contexto para transformá-los em entendimento.
- Objetivo claro: toda análise deveria existir para responder algo específico, não ser feita "só para ver o que aparece".

Por que analisar dados é importante:
- Porque decisões baseadas em evidências tendem a ser mais consistentes do que decisões baseadas apenas em opinião.
- Porque análise ajuda a identificar problemas antes que eles se tornem grandes.
- Porque permite medir se algo está funcionando (ou não) de forma objetiva.

Vale reforçar: análise de dados é, no fundo, um processo de investigação e interpretação — muito mais próximo de um raciocínio investigativo do que de uma tarefa puramente técnica ou matemática.

## O papel do analista de dados
O analista de dados é o profissional responsável por interpretar dados já coletados e organizados, transformando-os em informações e insights que ajudem na tomada de decisões melhores.

*O que o analista costuma fazer no dia a dia:*
- Explorar bases de dados para entender seu conteúdo e qualidade.
- Limpar e organizar dados antes de analisá-los.
- Responder perguntas de negócio através de consultas e análises.
- Criar relatórios, gráficos e dashboards.
- Identificar padrões, tendências e anomalias.
- Comunicar descobertas de forma clara para públicos não técnicos.

*Que tipo de problema ele ajuda a resolver:*
- "Por que as vendas caíram no último mês?"
- "Qual produto está performando melhor em cada região?"
- "Esse novo processo realmente reduziu o tempo de atendimento?"

Um ponto importante: analista de dados não é apenas "a pessoa que mexe com dados". Não basta saber usar ferramentas (Excel, SQL, Python) — o papel central do analista é o raciocínio: saber formular a pergunta certa, investigar com critério e interpretar os resultados com honestidade. As ferramentas são meios; a análise é o fim.

## O processo de trabalho do analista
De forma geral, o trabalho de um analista segue um fluxo parecido com este, independente da empresa ou do problema:
1. Entendimento do problema: entender o que está sendo perguntado e por quê. Muitas vezes a pergunta inicial não é exatamente o problema real, e cabe ao analista ajudar a esclarecer isso.
2. Investigação: explorar os dados disponíveis, entender sua origem, qualidade e limitações.
3. Análise: aplicar técnicas para extrair padrões, comparações e respostas relevantes.
4. Interpretação: dar sentido aos resultados encontrados, considerando o contexto do negócio.
5. Comunicação: apresentar as descobertas de forma clara, geralmente para pessoas que não têm conhecimento técnico.
6. Apoio à decisão: o resultado final do trabalho do analista serve para embasar uma decisão ou ação de outra pessoa (ou equipe).

## Do dado à ação: como gerar valor com dados
Um jeito prático de entender a "jornada" de um dado até virar valor real para uma empresa é pensar nesse fluxo:

Dados → Informação → Insight → Decisão → Ação

- Dados: valores brutos, sem contexto. Ex: o número "1200".
- Informação: dados com contexto e significado. Ex: "1200 unidades vendidas em julho".
- Insight: uma descoberta relevante e acionável a partir da informação. Ex: "as vendas de julho cresceram 20% em relação a junho, puxadas pela categoria X".
- Decisão: a escolha feita com base nesse insight. Ex: "vamos aumentar o investimento em marketing na categoria X".
- Ação: a execução prática dessa decisão. Ex: a campanha de marketing é de fato lançada.

> Em resumo: o valor dos dados não está apenas em coletá-los ou analisá-los, mas em utilizá-los para compreender problemas, orientar decisões e avaliar resultados.
