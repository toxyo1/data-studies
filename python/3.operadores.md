# 03 — Operadores

## Operador de atribuição (=)
O operador `=` é usado para atribuir um valor a uma variável — ele já apareceu bastante nos capítulos anteriores. É importante não confundir esse `=` (atribuição) com o `==` (comparação de igualdade), que veremos mais adiante:

```python
idade = 26   # atribuição: guarda o valor 26 na variável idade
```

## Operadores aritméticos
Realizam operações matemáticas:

- `+` Adição
- `-` Subtração
- `*` Multiplicação
- `/` Divisão (sempre retorna `float`, mesmo em divisões exatas)
- `//` Divisão inteira (descarta a parte decimal)
- `%` Módulo (retorna o resto da divisão)
- `**` Potenciação (exponenciação)

```python
print(10 / 3)    # 3.3333333333333335
print(10 // 3)   # 3
print(10 % 3)    # 1
print(2 ** 3)    # 8
```

## Operadores de atribuição composta
Combinam uma operação aritmética com a atribuição, atualizando o valor de uma variável de forma mais compacta:

- `+=` Soma e atribui
- `-=` Subtrai e atribui
- `*=` Multiplica e atribui
- `/=` Divide e atribui
- `//=` Divide (inteiro) e atribui
- `%=` Aplica módulo e atribui
- `**=` Eleva à potência e atribui

```python
pontos = 10
pontos += 5   # equivale a: pontos = pontos + 5
print(pontos) # 15
```

## Operadores de comparação
Comparam dois valores e retornam sempre um booleano (`True` ou `False`):

- `==` Igual a
- `!=` Diferente de
- `>` Maior que
- `<` Menor que
- `>=` Maior ou igual a
- `<=` Menor ou igual a

```python
print(10 >= 10)   # True
print(5 != 5)      # False
```

## Operadores lógicos
Utilizados para combinar ou inverter condições:

- `and`: Retorna `True` se todas as condições forem verdadeiras.
- `or`: Retorna `True` se pelo menos uma condição for verdadeira.
- `not`: Inverte o valor lógico (`not True` vira `False`).

```python
idade = 18
tem_cnh = True
pode_dirigir = idade >= 18 and tem_cnh   # True
```

## Operadores de identidade (is, is not)
Enquanto `==` compara se dois valores são **iguais**, os operadores `is` e `is not` verificam se duas variáveis apontam para o **mesmo objeto** na memória — o que não é a mesma coisa:

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)   # True  → os valores são iguais
print(a is b)   # False → são objetos diferentes na memória
```

Na prática, o mais comum é usar `==` para comparar valores no dia a dia. Já o `is` costuma ser reservado para casos específicos, como verificar se uma variável é `None`:

```python
resultado = None
print(resultado is None)   # forma recomendada, em vez de resultado == None
```

> **Nota avançada:** em alguns casos, como números inteiros pequenos (de -5 a 256), o Python (na implementação CPython) reaproveita o mesmo objeto na memória por otimização interna — então `a is b` pode retornar `True` mesmo sem nenhuma relação especial entre as variáveis. Esse é um detalhe de implementação, não uma regra da linguagem, e não deve ser usado como forma de comparar valores. Para comparar valores, use sempre `==`.

## Operadores de pertencimento (in, not in)
Verificam se um valor está (ou não) contido em uma sequência, como uma string (veremos isso de forma muito mais ampla quando estudarmos listas, tuplas e dicionários):

```python
fruta = "banana"

print("ana" in fruta)       # True  → "ana" está contido em "banana"
print("uva" not in fruta)   # True  → "uva" não está contido em "banana"
```

## Operadores bitwise
Operam diretamente sobre a representação **binária** dos números inteiros, bit a bit. São menos usados no dia a dia de quem está começando, mas aparecem em contextos como manipulação de flags, permissões e otimizações de baixo nível:

- `&` E binário (*AND*) — 1 apenas onde os dois bits são 1.
- `|` OU binário (*OR*) — 1 onde pelo menos um dos bits é 1.
- `^` OU exclusivo (*XOR*) — 1 onde os bits são diferentes entre si.
- `~` NÃO binário (*NOT*) — inverte todos os bits.
- `<<` Deslocamento à esquerda — desloca os bits para a esquerda (equivale a multiplicar por potências de 2).
- `>>` Deslocamento à direita — desloca os bits para a direita (equivale a dividir por potências de 2).

```python
print(5 & 3)    # 1   (0101 & 0011 = 0001)
print(5 | 3)    # 7   (0101 | 0011 = 0111)
print(5 << 1)   # 10  (desloca os bits de 5 uma casa à esquerda)
```

## Ordem de precedência
Quando vários operadores aparecem na mesma expressão, o Python segue uma ordem definida para decidir o que é calculado primeiro — da maior para a menor prioridade:

1. `()` Parênteses (prioridade máxima)
2. `**` Potenciação
3. `+x`, `-x`, `~x` Operadores unários (positivo, negativo, NOT binário)
4. `*`, `/`, `//`, `%` Multiplicação, divisões e resto
5. `+`, `-` Adição e subtração
6. `<<`, `>>` Deslocamento de bits
7. `&` E binário
8. `^` OU exclusivo binário
9. `|` OU binário
10. `in`, `not in`, `is`, `is not`, `<`, `<=`, `>`, `>=`, `!=`, `==` Comparações, pertencimento e identidade (todos com a mesma prioridade)
11. `not` Negação lógica
12. `and` Conjunção lógica
13. `or` Disjunção lógica

> Operadores no mesmo nível são avaliados da esquerda para a direita — exceto a potenciação (`**`), que é avaliada da direita para a esquerda. Na dúvida, o uso de parênteses sempre deixa a expressão mais clara (e evita bugs sutis), então não hesite em usá-los mesmo quando não forem estritamente necessários.
