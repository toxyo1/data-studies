# 02 — Tipos de Dados e Variáveis

## Variáveis - Criação e atribuição
Para criar uma variável, basta definir um nome e usar o operador `=` para atribuir um valor. O Python define o tipo automaticamente.

Uma variável pode ter seu valor e seu tipo alterados a qualquer momento atribuindo um novo valor a ela.

## Regras para nomes de variáveis
- Deve começar com uma letra ou sublinhado (`_`), nunca com número.
- Pode conter apenas letras, números e sublinhados (`a-z`, `0-9`, `_`).
- Diferencia maiúsculas de minúsculas (*case-sensitive*: `nome` é diferente de `Nome`).
- Não pode usar palavras reservadas da linguagem (como `if`, `for`, `class`).
- Convenção: usa-se o padrão `snake_case` (palavras em minúsculo separadas por `_`).

## Tipos de dados básicos
- **int**: Números inteiros, positivos ou negativos (ex.: `10`, `-5`).
- **float**: Números com casas decimais (ex.: `3.14`). Usa ponto `.`, nunca vírgula.
- **str**: Cadeia de caracteres (texto). Usa-se aspas simples ou duplas.
- **bool**: Representa apenas dois valores lógicos: `True` ou `False`. Letra inicial sempre maiúscula.
- **NoneType**: possui um único valor possível, `None`, que representa a **ausência de valor** — não é a mesma coisa que zero, string vazia ou `False`.
- **type()**: Função interna que retorna o tipo do dado ou da variável informada.

```python
idade = 26
print(type(idade))   # <class 'int'>

resultado = None
print(type(resultado))   # <class 'NoneType'>
```

## Reatribuição de variáveis e tipagem dinâmica
Como vimos no capítulo anterior, o Python define o tipo de uma variável automaticamente, de acordo com o valor atribuído. Isso significa que uma mesma variável pode "trocar de tipo" livremente ao longo do código, sem nenhum aviso ou erro — basta atribuir um novo valor:

```python
x = 10          # x é int
print(type(x))  # <class 'int'>

x = "dez"       # agora x é str
print(type(x))  # <class 'str'>
```

Isso não significa que o Python "converteu" o número em texto — o que acontece é que a variável `x` passou a apontar para um objeto diferente. Esse comportamento é o que caracteriza a **tipagem dinâmica**: o tipo pertence ao valor, não à variável.

## Atribuição múltipla e encadeada
O Python permite atribuir valores a várias variáveis em uma única linha, de duas formas:

**Atribuição múltipla** (cada variável recebe um valor diferente, na ordem):
```python
nome, idade, ativo = "Marian", 26, True
```

**Atribuição encadeada** (todas as variáveis recebem o mesmo valor):
```python
a = b = c = 0
```

Uma aplicação prática da atribuição múltipla é trocar o valor de duas variáveis sem precisar de uma variável auxiliar:
```python
a, b = 1, 2
a, b = b, a
print(a, b)  # 2 1
```

## Conversão de tipos (casting)
Como o Python tem tipagem forte, ele nunca converte tipos incompatíveis automaticamente (por exemplo, somar `"10"` com `5` gera erro). Quando essa conversão é necessária, ela deve ser feita de forma explícita, usando as funções de conversão:

- `int()` — converte para número inteiro.
- `float()` — converte para número com casas decimais.
- `str()` — converte para texto.
- `bool()` — converte para valor lógico.

```python
idade_texto = "26"
idade_numero = int(idade_texto)   # 26 (int)

preco = 19.9
preco_texto = str(preco)          # "19.9" (str)
```

**Cuidado com conversões inválidas.** Nem todo valor pode ser convertido para qualquer tipo — se a conversão não fizer sentido, o Python gera um erro (`ValueError`):

```python
int("vinte e seis")   # ValueError: invalid literal for int()
```

Também vale notar que `int()` **trunca** a parte decimal em vez de arredondar:
```python
int(9.9)   # 9, não 10
```

## Verificando tipos com isinstance()
Além da função `type()`, existe a função `isinstance()`, usada para verificar se um valor pertence a um determinado tipo. Ela é a forma recomendada de checar tipos dentro de condições, por ser mais flexível (inclusive lida bem com herança, assunto que veremos mais à frente em Programação Orientada a Objetos):

```python
idade = 26
print(isinstance(idade, int))   # True
print(isinstance(idade, str))   # False
```

## Mutabilidade dos tipos básicos
Um conceito importante que vai se tornar ainda mais relevante quando estudarmos listas, tuplas e dicionários é a **mutabilidade**: a possibilidade (ou não) de alterar um objeto depois que ele foi criado.

Todos os tipos básicos vistos até aqui (`int`, `float`, `str`, `bool`, `NoneType`) são **imutáveis** — ou seja, uma vez criado, o valor do objeto em si não pode ser alterado. Quando você "muda" uma variável, na verdade está criando um novo objeto e fazendo a variável apontar para ele:

```python
nome = "Marian"
id_antigo = id(nome)

nome = nome + " Lima"
id_novo = id(nome)

print(id_antigo == id_novo)   # False → é um objeto novo, não o mesmo "editado"
```

Esse comportamento é diferente do que veremos em listas e dicionários, que são **mutáveis** — mas isso fica para os próximos capítulos.

## Valores "truthy" e "falsy"
Em Python, todo valor pode ser avaliado como verdadeiro ou falso em um contexto lógico (como dentro de um `if`), mesmo sem ser um `bool` explicitamente. Valores considerados **falsy** (avaliados como `False`) incluem:

- `False`
- `None`
- `0` e `0.0`
- `""` (string vazia)

Qualquer outro valor é considerado **truthy** (avaliado como `True`). Isso permite escrever verificações mais diretas:

```python
nome = ""

if nome:
    print("Tem nome")
else:
    print("Nome vazio")   # é isso que será impresso
```

## Cuidado com a precisão de números float
Por causa de como números decimais são representados internamente pelo computador (em binário), operações com `float` podem gerar resultados com pequenas imprecisões:

```python
print(0.1 + 0.2)   # 0.30000000000000004, e não 0.3
```

Isso não é um "bug" do Python — é uma limitação de como qualquer linguagem de programação representa números decimais na memória. Na prática, isso significa que comparar dois `float` diretamente com `==` pode ser arriscado; o ideal é comparar se a diferença entre eles é suficientemente pequena, algo que veremos com mais detalhe quando estudarmos o módulo `math`.
