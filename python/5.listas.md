# 05 — Listas

## O que é uma lista?
Uma lista (`list`) é uma coleção **ordenada** e **mutável** de valores, que podem ser de tipos diferentes dentro de uma mesma lista. É uma das estruturas de dados mais usadas em Python, e serve para agrupar vários valores relacionados em uma única variável.

```python
numeros = [1, 2, 3, 4, 5]
nomes = ["Marian", "João", "Ana"]
mista = [1, "texto", True, 3.14]   # uma lista pode misturar tipos diferentes
```

## Criando listas
Listas são criadas com colchetes `[]`, com os elementos separados por vírgula. Também é possível criar uma lista vazia, ou converter outro tipo de dado em lista com a função `list()`:

```python
vazia = []
letras = list("Python")   # ['P', 'y', 't', 'h', 'o', 'n'] → transforma uma string em lista de caracteres
numeros = list(range(5))  # [0, 1, 2, 3, 4]
```

## Listas são mutáveis
Diferente das strings (vistas no capítulo anterior), listas são **mutáveis**: é possível alterar, adicionar ou remover elementos depois que a lista já foi criada, sem precisar criar um objeto novo:

```python
numeros = [1, 2, 3]
numeros[0] = 100
print(numeros)   # [100, 2, 3] → a própria lista foi alterada
```

> Essa mutabilidade é o principal ponto de contraste que veremos no próximo capítulo, sobre tuplas — que são praticamente idênticas às listas, exceto por serem imutáveis.

## Indexação e fatiamento
O acesso a elementos de uma lista funciona de forma muito parecida com o que já vimos em strings: índices começam em `0`, e índices negativos contam a partir do final.

```python
frutas = ["maçã", "banana", "uva", "laranja"]

print(frutas[0])     # maçã
print(frutas[-1])    # laranja
print(frutas[1:3])   # ['banana', 'uva']   (fatiamento, mesma lógica de strings)
print(frutas[::-1])  # ['laranja', 'uva', 'banana', 'maçã']   (lista invertida)
```

A diferença importante é que, como listas são mutáveis, é possível **atribuir um novo valor** a uma posição ou fatia:

```python
frutas[1] = "morango"
print(frutas)   # ['maçã', 'morango', 'uva', 'laranja']
```

## Operações com listas
Assim como com strings, listas suportam os operadores `+` (concatenação), `*` (repetição), `len()` (tamanho) e `in`/`not in` (pertencimento):

```python
a = [1, 2, 3]
b = [4, 5, 6]

print(a + b)        # [1, 2, 3, 4, 5, 6]
print(a * 2)        # [1, 2, 3, 1, 2, 3]
print(len(a))       # 3
print(3 in a)       # True
print(10 not in a)  # True
```

## Funções úteis: min(), max() e sum()
Para listas de números, três funções internas do Python são extremamente usadas no dia a dia:

- `min(lista)` — retorna o menor valor.
- `max(lista)` — retorna o maior valor.
- `sum(lista)` — retorna a soma de todos os valores.

```python
numeros = [10, 20, 30]

print(min(numeros))  # 10
print(max(numeros))  # 30
print(sum(numeros))  # 60
```

## Adicionando elementos
- `append(x)` — adiciona um único elemento ao final da lista.
- `insert(i, x)` — insere um elemento em uma posição específica.
- `extend(iteravel)` — adiciona **cada elemento** de outro iterável (outra lista, tupla, string etc.) ao final.

```python
frutas = ["maçã", "banana"]

frutas.append("uva")
print(frutas)   # ['maçã', 'banana', 'uva']

frutas.insert(1, "morango")
print(frutas)   # ['maçã', 'morango', 'banana', 'uva']

frutas.extend(["pera", "kiwi"])
print(frutas)   # ['maçã', 'morango', 'banana', 'uva', 'pera', 'kiwi']
```

> Cuidado: usar `append()` com uma lista dentro não junta os elementos, e sim adiciona a lista inteira como um único item:
> ```python
> a = [1, 2]
> a.append([3, 4])
> print(a)   # [1, 2, [3, 4]] → uma lista dentro da lista, não [1, 2, 3, 4]
> ```
> Para juntar os elementos de verdade, o método certo é `extend()`.

## Removendo elementos
- `remove(x)` — remove a **primeira ocorrência** do valor `x`. Gera `ValueError` se o valor não existir na lista.
- `pop(i)` — remove e **retorna** o elemento na posição `i` (se `i` não for informado, remove o último elemento).
- `clear()` — remove todos os elementos, deixando a lista vazia.
- `del lista[i]` — remove o elemento na posição `i` (é um comando, não um método da lista).

```python
numeros = [10, 20, 30, 40]

numeros.remove(20)
print(numeros)   # [10, 30, 40]

ultimo = numeros.pop()
print(ultimo)     # 40
print(numeros)    # [10, 30]

del numeros[0]
print(numeros)    # [30]

numeros.clear()
print(numeros)    # []
```

## Ordenação
- `sort()` — ordena a lista **no próprio lugar** (altera a lista original), em ordem crescente por padrão.
- `sorted(lista)` — retorna uma **nova lista** ordenada, sem alterar a lista original.
- `reverse()` — inverte a ordem dos elementos no próprio lugar.

```python
numeros = [5, 2, 8, 1]

numeros.sort()
print(numeros)   # [1, 2, 5, 8]

numeros.sort(reverse=True)
print(numeros)   # [8, 5, 2, 1]

original = [3, 1, 2]
nova = sorted(original)
print(original)   # [3, 1, 2] → não foi alterada
print(nova)        # [1, 2, 3]

letras = ["c", "a", "b"]
letras.reverse()
print(letras)   # ['b', 'a', 'c'] → apenas inverteu a ordem atual, não ordenou
```

Tanto `sort()` quanto `sorted()` aceitam o parâmetro `key`, que permite definir um critério de ordenação personalizado:

```python
nomes = ["Ana", "Jo", "Marian"]
nomes.sort(key=len)   # ordena pelo tamanho de cada string
print(nomes)   # ['Jo', 'Ana', 'Marian']
```

## Copiando listas — cuidado com a mutabilidade
Esse é um dos pontos que mais gera bugs em quem está começando. Quando você atribui uma lista existente a uma nova variável, **não está criando uma cópia** — as duas variáveis passam a apontar para o mesmo objeto na memória:

```python
lista1 = [1, 2, 3]
lista2 = lista1       # lista2 NÃO é uma cópia, é o mesmo objeto

lista2.append(4)
print(lista1)   # [1, 2, 3, 4] → lista1 também mudou!
print(lista1 is lista2)   # True
```

Para criar uma cópia de verdade (um objeto novo, independente), existem algumas formas:

```python
lista1 = [1, 2, 3]

copia1 = lista1.copy()
copia2 = lista1[:]        # fatiamento completo também copia
copia3 = list(lista1)     # usando o construtor list()

copia1.append(4)
print(lista1)   # [1, 2, 3] → não foi afetada
```

> Essas três formas fazem uma **cópia rasa** (*shallow copy*): funcionam bem para listas de valores simples (números, strings), mas se a lista tiver outras listas dentro dela (listas aninhadas), as listas internas ainda serão compartilhadas entre a original e a cópia. Esse detalhe mais avançado será revisitado quando estudarmos módulos, com a função `deepcopy()`.

## Buscando elementos
- `index(x)` — retorna o índice da primeira ocorrência de `x`. Gera `ValueError` se não encontrar.
- `count(x)` — retorna quantas vezes `x` aparece na lista.
- `in` / `not in` — verificam se um valor está (ou não) presente na lista.

```python
numeros = [10, 20, 30, 20, 40]

print(numeros.index(20))   # 1  (primeira ocorrência)
print(numeros.count(20))   # 2
print(30 in numeros)       # True
```

## Listas aninhadas
Uma lista pode conter outras listas dentro dela — o que é muito útil para representar dados em formato de tabela (linhas e colunas), por exemplo:

```python
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print(matriz[0])       # [1, 2, 3] → a primeira lista interna
print(matriz[1][2])    # 6 → segunda lista interna, terceiro elemento
```

## Percorrendo listas com for
Embora laços de repetição sejam vistos com profundidade em um capítulo próprio, vale adiantar que percorrer uma lista com `for` é uma das operações mais comuns do dia a dia:

```python
frutas = ["maçã", "banana", "uva"]

for fruta in frutas:
    print(fruta)
```

## Desempacotamento de listas
É possível atribuir os elementos de uma lista diretamente a variáveis separadas, na ordem em que aparecem — o mesmo princípio de atribuição múltipla que já vimos no capítulo 02:

```python
coordenadas = [10, 20, 30]
x, y, z = coordenadas
print(x, y, z)   # 10 20 30
```

Também é possível usar `*` para capturar "o restante" dos valores em uma lista à parte:

```python
numeros = [1, 2, 3, 4, 5]
primeiro, *meio, ultimo = numeros

print(primeiro)   # 1
print(meio)        # [2, 3, 4]
print(ultimo)      # 5
```
