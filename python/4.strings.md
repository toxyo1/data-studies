# 04 — Strings

## O que é uma string?
Uma string (`str`) é o tipo de dado usado para representar texto em Python — uma sequência de caracteres. Já vimos esse tipo brevemente no capítulo 02; agora vamos explorar tudo o que é possível fazer com ele.

## Criando strings
Strings podem ser criadas com aspas simples (`'...'`) ou aspas duplas (`"..."`) — não há diferença funcional entre elas, apenas estilo:

```python
nome = 'Marian'
sobrenome = "Lima"
```

Também é possível criar strings com aspas triplas (`'''...'''` ou `"""..."""`), que permitem que o texto ocupe **várias linhas**. Vale reforçar: isso cria uma string multilinha de verdade — não é um comentário (como já vimos no capítulo 01, `""" """` só vira documentação quando usado como docstring; aqui, atribuída a uma variável, é simplesmente uma string comum):

```python
texto = """Primeira linha
Segunda linha
Terceira linha"""
```

### Caracteres de escape
Alguns caracteres têm significado especial dentro de uma string e precisam ser "escapados" com uma barra invertida (`\`) para serem inseridos literalmente:

- `\n` — quebra de linha
- `\t` — tabulação
- `\\` — barra invertida literal
- `\'` — aspas simples literal (dentro de uma string com aspas simples)
- `\"` — aspas duplas literal (dentro de uma string com aspas duplas)

```python
print("Linha 1\nLinha 2")   # quebra em duas linhas
print("Ele disse: \"oi\"")  # Ele disse: "oi"
```

## Imutabilidade das strings
Assim como vimos no capítulo 02, strings são **imutáveis**: uma vez criada, não é possível alterar um caractere específico dela diretamente. Qualquer "modificação" na verdade cria uma nova string:

```python
nome = "Marian"
nome[0] = "M"   # TypeError: 'str' object does not support item assignment
```

Para "mudar" uma string, é preciso reatribuir a variável a um novo valor (como já vimos no capítulo 02, ao somar `" Lima"` a `nome`, por exemplo).

## Indexação
Cada caractere de uma string tem uma posição (índice), começando em `0` para o primeiro caractere. Também é possível usar índices **negativos**, que contam a partir do final da string:

```python
nome = "Python"

print(nome[0])    # P  (primeiro caractere)
print(nome[-1])   # n  (último caractere)
print(nome[2])    # t
```

## Fatiamento (slicing)
Fatiamento permite extrair um pedaço (uma "fatia") de uma string, usando a sintaxe `string[início:fim:passo]`. O caractere no índice `fim` **não é incluído** no resultado:

```python
nome = "Python"

print(nome[0:3])    # Pyt   (do índice 0 ao 2)
print(nome[:3])     # Pyt   (do início até o índice 2)
print(nome[3:])     # hon   (do índice 3 até o final)
print(nome[:])      # Python (cópia da string inteira)
```

O terceiro parâmetro (`passo`) permite pular caracteres — e, quando negativo, percorre a string de trás para frente:

```python
print(nome[::2])    # Pto   (pula de 2 em 2)
print(nome[::-1])   # nohtyP  (string invertida)
```

## Concatenação (+) e repetição (*)
Strings podem ser somadas (concatenadas) com `+`, e repetidas com `*`:

```python
saudacao = "Olá" + ", " + "mundo!"
print(saudacao)     # Olá, mundo!

linha = "-" * 10
print(linha)        # ----------
```

> Lembrando do capítulo 02: `+` entre string e número não funciona diretamente (`"idade: " + 26` gera erro) — é preciso converter o número com `str()` antes.

## len()
A função `len()` retorna a quantidade de caracteres de uma string (incluindo espaços):

```python
print(len("Python"))   # 6
```

## Operadores in / not in
Como vimos no capítulo de operadores, `in` e `not in` verificam se uma sequência de caracteres está contida dentro de uma string:

```python
frase = "Python é ótimo"

print("ótimo" in frase)      # True
print("Java" not in frase)   # True
```

## Comparação de strings
Strings podem ser comparadas com os operadores `==`, `!=`, `<`, `>`, `<=` e `>=`. Essa comparação é **lexicográfica**: o Python compara os caracteres da esquerda para a direita usando seus valores de código Unicode (obtidos através da função `ord()`), e para assim que encontra o primeiro par de caracteres diferentes — ou quando uma das strings termina antes da outra.

```python
print("banana" == "banana")   # True
print("banana" < "laranja")   # True → "b" tem código Unicode menor que "l"
```

> **Atenção**: para os caracteres básicos do alfabeto latino sem acentuação, vale a regra prática de que **dígitos (`0-9`) têm código Unicode menor que letras maiúsculas (`A-Z`), que por sua vez têm código menor que letras minúsculas (`a-z`)** — por isso `"Z" < "a"` é `True`. Mas essa regra vale apenas para esses caracteres básicos: ela **não é uma regra universal** de toda a tabela Unicode, que também inclui letras acentuadas, caracteres de outros alfabetos, emojis etc., cada um com seu próprio código, nem sempre seguindo essa mesma lógica.

## Métodos mais usados de strings
Strings possuem diversos métodos prontos para facilitar tarefas comuns. Vamos organizá-los em quatro grupos, de acordo com o que fazem.

### Métodos de modificação e limpeza
Alteram a forma como o texto é exibido — caixa (maiúsculas/minúsculas), espaçamento e preenchimento.

```python
texto = "Python é Incrível"

print(texto.upper())        # PYTHON É INCRÍVEL
print(texto.lower())        # python é incrível
print(texto.capitalize())   # Python é incrível (só a primeira letra maiúscula)
print(texto.title())        # Python É Incrível (primeira letra de cada palavra)
print(texto.swapcase())     # pYTHON É iNCRÍVEL (inverte maiúsculas e minúsculas)
```

`casefold()` é parecido com `lower()`, mas foi pensado para **comparações seguras entre textos internacionais** — ele trata certos caracteres especiais de forma mais agressiva que o `lower()`. Um exemplo clássico é o `ß` do alemão, que `casefold()` converte para `ss`:

```python
palavra = "straße"
print(palavra.lower())      # straße   (o ß permanece)
print(palavra.casefold())   # strasse (o ß vira "ss")
```

**Remoção de espaços (ou outros caracteres) das extremidades:**
```python
texto = "   olá   "

print(texto.strip())    # "olá" (remove espaços das duas pontas)
print(texto.lstrip())   # "olá   " (remove só da esquerda)
print(texto.rstrip())   # "   olá" (remove só da direita)
```

Esses três métodos também aceitam um argumento indicando quais caracteres remover (não apenas espaços):
```python
print("###aviso###".strip("#"))   # "aviso"
```

**Preenchimento e alinhamento** — úteis para formatar texto em colunas ou códigos com tamanho fixo:
```python
codigo = "42"
print(codigo.zfill(5))          # "00042"  (preenche com zeros à esquerda)

print("Menu".center(10))        # "   Menu   "  (centraliza, preenche com espaço)
print("Menu".center(10, "-"))   # "---Menu---"

print("Python".ljust(10, "."))  # "Python...."  (alinha à esquerda, preenche à direita)
print("Python".rjust(10, "."))  # "....Python"  (alinha à direita, preenche à esquerda)
```

**Substituição e remoção de prefixo/sufixo:**
```python
frase = "Eu gosto de Java"
print(frase.replace("Java", "Python"))   # Eu gosto de Python

arquivo = "relatorio.pdf"
print(arquivo.removesuffix(".pdf"))   # relatorio
print(arquivo.removeprefix("relatorio"))   # .pdf
```

> `removeprefix()` e `removesuffix()` só existem a partir do **Python 3.9** — em versões anteriores, é preciso remover manualmente com fatiamento ou `startswith()`/`endswith()`.

### Métodos de divisão, partição e junção
Usados para separar (ou juntar) uma string em partes.

- `split()` — divide usando espaços (ou outro separador informado) e retorna uma lista.
- `rsplit()` — igual ao `split()`, mas conta as divisões a partir do final.
- `splitlines()` — divide uma string em linhas, retornando uma lista com cada linha.
- `partition()` — divide a string em exatamente três partes: antes do separador, o separador e depois do separador.
- `rpartition()` — igual ao `partition()`, mas busca o separador a partir do final.
- `join()` — junta uma lista de strings em uma só, usando um separador entre elas.

```python
texto = "python dados engenharia"
print(texto.split())   # ['python', 'dados', 'engenharia']

texto2 = "python_dados_engenharia"
print(texto2.rsplit("_", 1))   # ['python_dados', 'engenharia']

linhas = "linha 1\nlinha 2\nlinha 3"
print(linhas.splitlines())   # ['linha 1', 'linha 2', 'linha 3']

config = "timeout=30"
print(config.partition("="))   # ('timeout', '=', '30')

caminho = "pasta/subpasta/arquivo.txt"
print(caminho.rpartition("/"))   # ('pasta/subpasta', '/', 'arquivo.txt')

palavras = ["Engenharia", "de", "Software"]
print(" ".join(palavras))   # Engenharia de Software
```

> No exemplo de `rsplit("_", 1)`, o segundo argumento (`1`) limita a divisão a **no máximo uma vez**, contando a partir do final — por isso o resultado é `['python_dados', 'engenharia']`, e não uma lista com três elementos.

### Métodos de busca, posição e contagem
Permitem localizar, verificar e contar informações dentro de uma string. Vários deles aceitam os parâmetros opcionais `start` e `end`, que limitam a busca a um trecho específico da string (`end` não é incluído na busca).

- `find(sub)` — retorna o índice da primeira ocorrência de `sub`; `-1` se não encontrar.
- `rfind(sub)` — igual ao `find()`, mas busca a partir do final.
- `index(sub)` — igual ao `find()`, mas gera um erro (`ValueError`) se não encontrar, em vez de retornar `-1`.
- `rindex(sub)` — igual ao `index()`, mas busca a partir do final.
- `count(sub)` — conta quantas vezes `sub` aparece na string, **sem reaproveitar caracteres já contados** em outra ocorrência (por isso, em `"aaaa"`, `"aa"` aparece 2 vezes, e não 3).
- `startswith(prefixo)` / `endswith(sufixo)` — verificam se a string começa/termina com o valor informado (aceitam também uma tupla de valores possíveis).

```python
frase = "dados e analise de dados"
print(frase.find("dados"))    # 0  (primeira ocorrência)
print(frase.rfind("dados"))   # 19 (última ocorrência)

texto = "python_estudos"
print(texto.index("estudos"))   # 7
print(texto.rindex("o"))        # 12

texto2 = "banana nanica"
print(texto2.count("a"))        # 5
print(texto2.count("na", 4))    # 2  (busca a partir do índice 4)

arquivo = "relatorio_final.csv"
print(arquivo.startswith("relatorio"))   # True
print(arquivo.endswith(".txt"))          # False
print(arquivo.endswith((".csv", ".xlsx", ".json")))   # True (aceita tupla de opções)
```

### Métodos de validação (retorno booleano)
Verificam o conteúdo de uma string e retornam `True` ou `False`.

- `isalpha()` — apenas letras.
- `isalnum()` — apenas letras e/ou números.
- `isspace()` — apenas espaços em branco (espaço, `\t`, `\n`).
- `islower()` / `isupper()` — todas as letras minúsculas / maiúsculas.
- `istitle()` — segue o padrão de título (primeira letra de cada palavra maiúscula).
- `isdecimal()` — apenas dígitos decimais "puros".
- `isdigit()` — dígitos decimais e mais alguns caracteres Unicode que representam números, como `"²"`.
- `isnumeric()` — ainda mais abrangente que `isdigit()`: inclui frações (`"½"`) e numerais de outros sistemas de escrita, como algarismos romanos (`"Ⅳ"`).
- `isidentifier()` — verifica se o texto poderia ser usado como nome de variável, função ou classe válido em Python.
- `isprintable()` — `False` se a string contiver caracteres de controle invisíveis, como quebra de linha (`\n`) ou tabulação (`\t`).

```python
print("Python".isalpha())    # True
print(" \n\t".isspace())     # True

print("python".islower())    # True
print("PYTHON".isupper())    # True
print("Python".islower())    # False (tem letra maiúscula)

print("Python É Incrível".istitle())   # True
print("Python é incrível".istitle())   # False ("é" está em minúsculo)

print("123".isdecimal())     # True
print("²".isdecimal())       # False → isdecimal() não aceita esse caractere
print("²".isdigit())         # True  → isdigit() aceita
print("½".isnumeric())       # True  → isnumeric() vai além, aceita frações

print("Python".isidentifier())   # True
print("2 python".isidentifier()) # False (não pode começar com número nem ter espaço)

print("Python".isprintable())    # True
print("Python\n".isprintable())  # False → contém quebra de linha
```

> `isdecimal()`, `isdigit()` e `isnumeric()` parecem sinônimos, mas têm abrangências diferentes e crescentes: `isdecimal()` é o mais restrito, `isdigit()` inclui um pouco mais, e `isnumeric()` é o mais abrangente dos três.

## f-strings — formatando strings
F-strings (*formatted string literals*) são a forma mais moderna e legível de combinar texto fixo com variáveis ou expressões. Basta colocar a letra `f` antes das aspas e escrever a variável ou expressão entre chaves `{}`:

```python
nome = "Marian"
idade = 26

print(f"Nome: {nome} - Idade: {idade}")
print(f"Idade ano que vem: {idade + 1}")   # expressões também funcionam dentro das chaves
```

### Especificadores de formatação
Depois da expressão, é possível adicionar `:` seguido de um especificador de formatação, para controlar como o valor será exibido:

```python
preco = 19.9

print(f"{preco:.2f}")     # 19.90  → duas casas decimais
print(f"{1234567:,}")     # 1,234,567  → separador de milhar
print(f"{0.256:.1%}")     # 25.6%  → formata como porcentagem
```

> O separador de milhar com `,` segue a convenção **do Python** (e da maioria das linguagens de programação), não a convenção brasileira (que usa ponto para milhar e vírgula para decimal). Se precisar exibir números no formato brasileiro, será necessário formatar manualmente ou usar o módulo `locale` — assunto fora do escopo deste capítulo.

Também é possível controlar alinhamento e largura mínima do texto — muito útil para alinhar colunas em uma saída no terminal:

```python
print(f"{'nome':<10}|")   # "nome      |"  → alinhado à esquerda, 10 caracteres
print(f"{'nome':>10}|")   # "      nome|"  → alinhado à direita
print(f"{'nome':^10}|")   # "  nome    |"  → centralizado
```

### Chaves literais
Como `{}` tem significado especial dentro de uma f-string, para exibir uma chave literal é preciso duplicá-la:

```python
print(f"{{isso não é uma variável}}")   # {isso não é uma variável}
```

### Self-documenting expressions (`=`)
Desde o Python 3.8, é possível adicionar um `=` logo após a expressão para exibir tanto o código quanto o valor — muito útil para depuração rápida:

```python
x = 10
print(f"{x=}")          # x=10
print(f"{x + 5=}")      # x + 5=15
```
