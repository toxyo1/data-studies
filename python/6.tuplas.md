# 06 — Tuplas

## O que é uma tupla?
Uma tupla (`tuple`) é muito parecida com uma lista: uma coleção **ordenada** de valores, que podem ser de tipos diferentes. A grande diferença é que a tupla é **imutável** — depois de criada, não é possível adicionar, remover ou alterar seus elementos.

```python
coordenadas = (10, 20)
pessoa = ("Marian", 26, True)
```

## Criando tuplas
Tuplas são criadas com parênteses `()`, com os elementos separados por vírgula. Na prática, os parênteses são **opcionais** — o que realmente define uma tupla é a vírgula:

```python
a = (1, 2, 3)
b = 1, 2, 3        # também é uma tupla, mesmo sem parênteses
print(a == b)       # True
```

**Atenção com tuplas de um único elemento**: é preciso colocar uma vírgula depois do valor, mesmo com apenas um item — caso contrário, o Python entende os parênteses apenas como agrupamento matemático, não como uma tupla:

```python
nao_e_tupla = (5)     # isso é só o número 5, entre parênteses
print(type(nao_e_tupla))   # <class 'int'>

e_tupla = (5,)         # a vírgula é o que cria a tupla
print(type(e_tupla))   # <class 'tuple'>
```

Uma tupla vazia pode ser criada com `()` ou com a função `tuple()`:
```python
vazia = ()
vazia2 = tuple()
```

## Tuplas são imutáveis
Depois de criada, uma tupla não pode ter seus elementos alterados, adicionados ou removidos:

```python
pessoa = ("Marian", 26)
pessoa[1] = 27   # TypeError: 'tuple' object does not support item assignment
```

> **Nota importante**: a imutabilidade da tupla vale para a **estrutura** dela (não é possível trocar, adicionar ou remover elementos), mas se um dos elementos guardados dentro da tupla for, ele próprio, um objeto mutável (como uma lista), esse objeto interno ainda pode ser modificado normalmente:
> ```python
> dados = ("Marian", [90, 85, 92])
> dados[1].append(100)   # funciona! estamos alterando a lista, não a tupla
> print(dados)   # ('Marian', [90, 85, 92, 100])
> ```

## Indexação e fatiamento
Assim como em listas, é possível acessar elementos por índice (positivo ou negativo) e fazer fatiamento — mas sempre apenas para **leitura**, já que não é possível reatribuir uma posição da tupla:

```python
cores = ("vermelho", "verde", "azul", "amarelo")

print(cores[0])      # vermelho
print(cores[-1])     # amarelo
print(cores[1:3])    # ('verde', 'azul')
print(cores[::-1])   # ('amarelo', 'azul', 'verde', 'vermelho')
```

## Operações com tuplas
Tuplas suportam os mesmos operadores básicos que listas: `+` (concatenação, sempre gerando uma tupla nova), `*` (repetição), `len()` e `in`/`not in`:

```python
a = (1, 2, 3)
b = (4, 5, 6)

print(a + b)         # (1, 2, 3, 4, 5, 6)
print(a * 2)         # (1, 2, 3, 1, 2, 3)
print(len(a))        # 3
print(2 in a)        # True
```

## Métodos de tuplas
Por serem imutáveis, tuplas têm muito menos métodos que listas — afinal, não existe como "adicionar" ou "remover" elementos. Restam apenas dois, ambos herdados do mesmo princípio que já vimos em listas:

- `count(x)` — conta quantas vezes `x` aparece na tupla.
- `index(x)` — retorna o índice da primeira ocorrência de `x` (gera `ValueError` se não encontrar).

```python
numeros = (1, 2, 2, 3, 2)

print(numeros.count(2))   # 3
print(numeros.index(3))   # 3
```

## Empacotamento e desempacotamento
Criar uma tupla atribuindo vários valores de uma vez é chamado de **empacotamento** (*packing*). O processo inverso — distribuir os valores de uma tupla em variáveis separadas — é o **desempacotamento** (*unpacking*), que já vimos brevemente no capítulo de listas:

```python
# empacotamento
ponto = 10, 20, 30   # os três valores são "empacotados" em uma tupla

# desempacotamento
x, y, z = ponto
print(x, y, z)   # 10 20 30
```

O `*` também funciona aqui para capturar múltiplos valores em uma lista à parte:
```python
primeiro, *meio, ultimo = (1, 2, 3, 4, 5)
print(primeiro)   # 1
print(meio)        # [2, 3, 4]
print(ultimo)      # 5
```

> O desempacotamento de tuplas é usado o tempo todo em Python — inclusive quando uma função retorna múltiplos valores de uma vez (assunto que veremos em detalhe no capítulo de funções), o retorno é, na prática, uma tupla sendo desempacotada.

## Tuplas aninhadas
Assim como listas, tuplas também podem conter outras tuplas (ou até listas) dentro delas:

```python
pessoa = ("Marian", (1, 9, 2000))   # nome e data de nascimento

print(pessoa[1])      # (1, 9, 2000)
print(pessoa[1][2])   # 2000
```

## Convertendo entre lista e tupla
É possível converter uma lista em tupla e vice-versa usando as funções `tuple()` e `list()`:

```python
lista = [1, 2, 3]
tupla = tuple(lista)
print(tupla)   # (1, 2, 3)

tupla2 = (4, 5, 6)
lista2 = list(tupla2)
print(lista2)   # [4, 5, 6]
```

Isso é útil, por exemplo, quando você precisa "destravar" temporariamente uma tupla para modificá-la: converte para lista, faz as alterações, e converte de volta para tupla.

## Tuplas como chaves de dicionário (nota avançada)
Um benefício prático da imutabilidade é que tuplas (desde que contenham apenas elementos também imutáveis) são **hasheáveis** — ou seja, podem ser usadas como chave em um dicionário ou como elemento de um `set`, algo que uma lista jamais poderia fazer, por ser mutável:

```python
coordenadas_visitadas = {
    (0, 0): "início",
    (1, 2): "encontrou um item"
}
```

Vamos entender esse conceito de "hasheável" com mais profundidade no capítulo de dicionários — por enquanto, o importante é saber que essa é uma vantagem prática real da tupla sobre a lista, e não apenas uma limitação.

## Quando usar tupla em vez de lista?
Como listas e tuplas são tão parecidas, é comum surgir a dúvida de qual usar em cada situação. Algumas boas referências:

- Use **tupla** quando os dados representam algo fixo, que não deve mudar durante a execução do programa (ex: coordenadas, um registro de dados, os dias da semana).
- Use **lista** quando os dados vão ser modificados ao longo do tempo (adicionar, remover, reordenar itens).
- Tuplas também comunicam **intenção** para quem lê o código: usar uma tupla é como dizer "isso aqui não deveria mudar", o que deixa o código mais claro e menos propenso a erros.
