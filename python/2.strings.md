# 02 — Strings: Conceitos Fundamentais e Criação - O que são strings?
Uma string é uma sequência ordenada de caracteres utilizada para armazenar e representar texto. Suas principais características são:
- Sequência ordenada: Cada caractere ocupa uma posição específica na sequência, identificada por um índice.
- Imutabilidade: Uma string não pode ter seu conteúdo alterado depois de criada, seu conteúdo não pode ser alterado no mesmo espaço de memória. Qualquer modificação, na verdade cria um novo objeto.
- Aspas simples e duplas: Podem ser declaradas usando aspas simples (`' '`) ou aspas duplas (`" "`).

## Caracteres de escape e Raw strings
A barra invertida (\) permite representar caracteres especiais em uma string:

\n: Quebra de linha.
\t: Tabulação.
\\: Barra invertida.
\': Aspas simples.
\": Aspas duplas.

Para tratar a barra invertida como um caractere comum, usamos raw strings(utilizadas em caminhos de arquivos e regex),adicionando r antes das aspas.

* exemplo:
variavel = r"C:\novos_arquivos\tabelas"
print(variavel) # C:\novos_arquivos\tabelas

## Acesso aos caracteres por posição e fatiamento
Cada caractere possui uma posição(índice). Os índices positivos começam em 0 e os negativos começam em -1, contando a partir do final. Não existe índice -0. Já o fatiamento permite pegar uma parte da string usando [início:fim] ou [início:fim:salto]. O índice fim não é incluído no resultado.

* exemplo de fatiamento:
variavel = ""
print(variável[índice])
* exemplo de fatiamento:
variavel = ""
print(variável[ínicio:fim])
print(variável[início:fim:salto])

## Concatenação com operador `+`
Permite juntar duas ou mais strings usando o operador `+`. Para concatenar outros tipos, é necessário convertê-los para `str`.

* exemplo de concatenação:
print(variável1 + " " + variável2)

## Função len() 
Retorna a quantidade de caracteres da string (incluindo espaços e pontuação).

* exemplo:
print(len(variável))

## Operadores de pertinência (`in` e `not in`)
Verificam se um texto ou parte dele está presente ou não em outra string, retornando True ou False (booleano). A busca diferencia letras maiúsculas de minúsculas.

* exemplo:
frase = "aprendendo python"
print("java" in frase) #False //// *verificando se o texto existe na string*

## Comparação de strings (==, !=, <, >, <=, >=)
Os operadores de comparação permitem comparar dois valores e sempre retornam um resultado booleano: True ou False.

==: Igual a
!=: Diferente de
>: Maior que
<: Menor que
>=: Maior ou igual a
<=: Menor ou igual a

## Métodos de Modificação e Limpeza
Esses métodos permitem alterar a forma como os caracteres são escritos, como transformar letras maiúsculas ou minúsculas, além de ajustar a capitalização do texto recebido como entrada.
- upper(): converte para maiúsculas.
- lower(): converte para minúsculas.
- capitalize(): deixa o primeiro caractere maiúsculo e os demais minúsculos.
- title(): deixa a primeira letra de cada palavra maiúscula.
- swapcase(): inverte maiúsculas e minúsculas.
- casefold(): usada para comparações seguras de textos internacionais (ex.: converte o caractere alemão `ß` para `ss`).
- strip(): remove espaços ou outros caracteres das duas extremidades da string.
- lstrip(): remove espaços ou outros caracteres do lado esquerdo.
- rstrip(): remove espaços ou outros caracteres do lado direito.
- zfill(): adiciona zeros à esquerda até atingir o tamanho desejado.
- center(): centraliza o texto e também adiciona caracteres de preenchimento.
- ljust(): alinha o texto à esquerda e preenche o espaço restante.
- rjust(): alinha o texto à direita e preenche o espaço restante.
- replace(): permite substituir uma parte do texto por outra.
- removeprefix(): remove um texto específico do início da string.
- removesuffix(): remove um texto específico do final da string.

* exemplo upper:
variavel = "linguagem PYTHON"
print(variavel.upper()) # "LINGUAGEM PYTHON"

* exemplo strip:
variavel = "   Python   " 
print(variável.strip()) # "Python" 
print(variável.strip("caractere a ser removido"))

* exemplo zfill:
variavel = ""
print(variavel.zfill(tamanho desejado))
print(variavel.center(tamanho))
print(variavel.center(tamanho, "caractere de preenchimento"))

* exemplo replace:
frase = "Eu gosto de Java"
print(frase.replace("Java", "Python")) #Eu gosto de Python

* exemplo suffix:
arquivo = "relatorio.pdf"
print(arquivo.removesuffix(".pdf")) #relatorio

## Métodos de Divisão, Partição e Junção
Métodos usados para separar uma string em partes.
- split(): divide usando espaços ou outro separador informado e retorna uma lista.
- splitlines(): divide uma string em linhas e retorna uma lista com cada linha.
- rsplit(): faz o mesmo que split, mas começa a divisão pelo final.
- partition(): divide uma string em três partes: antes do separador, o separador e depois do separador.
- rpartition(): faz o mesmo que partition(), mas começa pelo final da string.
- join(): permite juntar várias strings em uma só, usando um separador entre elas.

* exemplo split:
texto = "python dados engenharia"
print(texto.split()) # ['python', 'dados', 'engenharia']

* exemplo rsplit:
texto = "python_dados_engenharia"
print(texto.rsplit("_", 1)) # ['python_dados', 'arquivo']

* partition:
config = "timeout=30"
print(config.partition("=")) # ('timeout', '=', '30')

* join:
palavras = ["Engenharia", "de", "Software"]
frase = " ".join(palavras)
print(frase) # Engenharia de Software

## Métodos de Busca, Posição e Contagem
Esses métodos permitem localizar, verificar e contar informações dentro de uma string, como encontrar a posição de um trecho, verificar se o texto começa ou termina com determinado conteúdo e contar quantas vezes algo aparece.
- find(sub[, start[, end]]): procura a primeira vez que sub (texto procurado) aparece e retorna o índice do seu primeiro caractere. se não encontrar, retorna -1.
- rfind(sub[, start[, end]]): procura a última vez que sub (texto procurado) aparece e retorna o índice do seu primeiro caractere. se não encontrar, retorna -1.
- index(sub[, start[, end]]): procura a primeira vez que sub aparece e retorna sua posição. Se não encontrar, gera um erro ValueError.
- rindex(sub[, start[, end]]): procura a última vez que sub aparece e retorna sua posição. Se não encontrar, gera um erro ValueError.
- count(sub[, start[, end]])`: retorna a quantidade total de vezes que uma substring apareceu no texto. o count() não reutiliza caracteres já contados em outra ocorrência. por exemplo, em "aaaa", "aa" aparece 2 vezes, e não 3.
- startswith(prefix[, start[, end]]): verifica se o texto inicia com o prefixo informado.
- endswith(suffix[, start[, end]]): verifica se o texto termina com o sufixo informado.

**sub:** texto que será procurado.
**start:** índice onde a busca começa.
**end:** índice onde a busca termina (não é incluído).

* exemplo find e rfind:
frase = "dados e analise de dados"
print(frase.find("dados")) # 0
print(frase.rfind("dados"))# 19

frase.find("sub", start, end) ou frase.find("dados", 5, 20)

* exemplo index e rindex:
texto = "python_estudos"
print(texto.index("estudos"))     # 7
print(texto.rindex("o"))          # 12

* exemplo count:
texto = "banana nanica"
print(texto.count("a"))          # 5
print(texto.count("na", 4))      # 2 (a partir do indice 4)

* exemplo starstwith e endswith:
arquivo = "relatorio_final.csv"
print(arquivo.startswith("relatorio"))  # True
print(arquivo.endswith(".txt"))         # False

* exemplo de verificacao de multiplas extensoes com tupla:
print(arquivo.endswith((".csv", ".xlsx", ".json")))  # True

## Métodos de Validação (Retorno Booleano)
Esses métodos verificam o conteúdo de uma string e retornam True ou False.
- isalpha(): verifica se contém apenas letras.
- isalnum(): verifica se contém apenas letras e números.
- isspace(): verifica se contém apenas espaços em branco, como espaço, \t e \n.
- islower(): verifica se todas as letras estão minúsculas.
- isupper(): verifica se todas as letras estão maiúsculas.
- istitle(): verifica se o texto segue o padrão de título.
- isdecimal(): verifica se contém apenas dígitos decimais.
- isdigit(): verifica se contém dígitos decimais e alguns outros, como ².
- isnumeric(): verifica se contém caracteres numéricos, incluindo frações como ½ e números romanos como Ⅳ.
- isidentifier(): verifica se pode ser usado como identificador no Python, como nome de variável, função ou classe.
- isprintable(): retorna True se todos os caracteres puderem ser exibidos na tela. Retorna False caso contenha caracteres de controle invisíveis, como quebras de linha (\n) ou tabulações (\t).


* exemplo validação de texto e espaço:
print("Python".isalpha())      # True
print("   \n\t".isspace())     # True

## Formatação de Strings
Esses recursos permitem intercalar variáveis, números e expressões diretamente dentro de um texto, controlando a apresentação dos dados.
- Operador `%`: forma antiga de inserir valores em uma string usando marcadores como `%s`, `%d` e `%f`.
- f-strings: permitem inserir variáveis e expressões diretamente dentro da string usando `{}` e o prefixo `f`.

Principais marcadores do operador %:
- %s: converte e exibe o valor como string.
- %d: formata como número inteiro.
- %f: formata como número de ponto flutuante (`%.2f` delimita para 2 casas decimais).

* exemplo interpolação clássica com %:
nome = "Marian"
idade = 25
texto = "Nome: %s | Idade: %d (nome, idade, preco)
print(texto) # Nome: Marian | Idade: 25 

* exemplo f-strings:
produto = "Teclado"
valor = 250.0
print(f"Produto: {produto} | Valor: R$ {valor:.2f}")

**As chaves {} podem conter expressões matemáticas e métodos.**

print(f"Com 10% de desconto: R$ {valor * (1 - desconto):.2f}")
print(f"Identificador: {produto.upper()}")

## Boas Práticas e Performance
Algumas práticas ajudam a trabalhar com strings de forma mais clara e segura.
- prefira f-strings para formatação, elas facilitam a inserção de variáveis e expressões dentro de strings.
- use o método adequado para cada situação, por exemplo, strip() para remover espaços, replace() para substituir textos e split() para dividir uma string.
- lembre-se da imutabilidade, métodos como upper(), replace() e strip() não alteram a string original. eles retornam uma nova string.
