# 01 — Fundamentos: O que é Python?
Python é uma linguagem de programação moderna projetada para priorizar a legibilidade e a simplicidade do código. Suas principais características são:

- **Alto nível**: Sintaxe simples e próxima da linguagem humana.
- **Interpretada**: Executa o código linha por linha, sem precisar de compilação prévia.
- **Tipagem dinâmica**: Em Python, não é necessário declarar o tipo das variáveis. O interpretador identifica automaticamente o tipo de acordo com o valor atribuído.
- **Tipagem forte**: Não junta tipos incompatíveis automaticamente (ex.: somar texto com número gera erro).
- **Multiparadigma**: Aceita diferentes estilos de programação (orientada a objetos, funcional e procedural).

## Interpretador e REPL
O **interpretador** é o programa responsável por ler e executar o código Python, linha por linha — diferente de linguagens compiladas, que transformam todo o código em um executável antes de rodar.

Existem duas formas principais de executar código Python:

- **Rodando um arquivo .py**: o interpretador lê o arquivo inteiro e executa as instruções em ordem.
- **REPL (Read-Eval-Print Loop)**: um modo interativo, acessado digitando python (ou python3) no terminal, onde cada linha digitada é lida, executada e o resultado é mostrado imediatamente — sem precisar salvar um arquivo. É muito usado para testar pequenos trechos de código rapidamente.

## Sintaxe básica - Estrutura e Indentação
- **Execução**: O código é lido de cima para baixo, linha por linha. Não usa ponto e vírgula para encerrar comandos.
- **Indentação**: É o espaçamento no início da linha (a margem esquerda, geralmente feita com 4 espaços ou a tecla Tab).

Enquanto outras linguagens usam chaves `{ }` para agrupar linhas de código, o Python usa apenas esse recuo para saber o que está dentro ou fora de uma estrutura (como uma condição, laço ou função).

Exemplo prático:
```python
if True:
    print("Linha recuada: está DENTRO do if")

print("Linha sem recuo: está FORA do if")
```

## Comentários
Comentários são usados para documentar ou desativar temporariamente uma linha de código, e são **sempre feitos com `#`**. Tudo que vem depois do `#` na mesma linha é ignorado pelo interpretador:

```python
# Isso é um comentário de uma linha
idade = 26  # também pode vir depois de uma linha de código
```

> **Atenção**: é comum ver por aí `""" """` sendo usado como se fosse um "comentário de várias linhas" — isso não é tecnicamente correto. `""" """` cria uma *string* (texto) multilinha; se ela não for atribuída a nada, o interpretador simplesmente a ignora na prática, o que faz parecer um comentário. Mas o uso correto desse recurso é outro: quando colocada como a primeira instrução de um módulo, função ou classe, essa string vira uma **docstring** — um texto de documentação oficial daquele trecho de código, que inclusive pode ser acessado depois pelo Python. Isso será visto com mais detalhe no capítulo de funções.

## Convenções de código
Python tem um guia de estilo oficial chamado **PEP 8**, que será estudado em profundidade mais adiante — mas algumas convenções básicas já valem a pena conhecer desde já:

- Usar **4 espaços** por nível de indentação (não misturar com Tab).
- Um comando por linha.
- Nomes descritivos para variáveis e funções (evitar nomes como `x`, `a1`, `temp` sempre que possível).
- Padrão `snake_case` para nomes de variáveis e funções (isso será detalhado no próximo capítulo).

## Palavras reservadas
Palavras reservadas (ou *keywords*) são termos que já têm um significado especial na linguagem, e por isso não podem ser usados como nome de variável, função ou qualquer outro identificador. As palavras reservadas do Python são:

```text
False      await      else       import     pass
None       break      except     in         raise
True       class      finally    is         return
and        continue   for        lambda     try
as         def        from       nonlocal   while
assert     del        global     not        with
async      elif       if         or         yield
```

Não é preciso decorar essa lista agora — ao longo do material, cada uma dessas palavras vai aparecer no seu devido contexto.

## print()
A função `print()` é usada para exibir informações no terminal. Ela aceita um ou mais valores, separados por vírgula:

```python
print("Olá, mundo!")
print("Nome:", "Marian", "-", "Idade:", 26)
```

Quando vários valores são passados separados por vírgula, o Python insere um espaço entre eles automaticamente. Também é possível controlar esse comportamento com os parâmetros `sep` (separador) e `end` (o que é impresso ao final, por padrão uma quebra de linha):

```python
print("Marian", "Lima", sep="-")     # Marian-Lima
print("Carregando", end="...")       # não pula linha ao final
print("concluído")
```

## input()
A função `input()` é usada para capturar dados digitados pelo usuário diretamente no terminal:

```python
nome = input("Digite seu nome: ")
```

Um ponto essencial: **tudo que `input()` retorna é sempre uma string** — mesmo que o usuário digite apenas números. Isso significa que, para usar esse valor em cálculos matemáticos, é necessário convertê-lo explicitamente (algo que veremos em detalhe no próximo capítulo, sobre tipos de dados).

```python
idade = input("Digite sua idade: ")
print(type(idade))   # <class 'str'>, mesmo que o usuário digite "26"
```
