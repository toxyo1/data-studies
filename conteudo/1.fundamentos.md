# 01 — Fundamentos

## O que é Python?
Python é uma linguagem de programação moderna projetada para priorizar a legibilidade e a simplicidade do código. Suas principais características são: 
Alto nível: Sintaxe simples e próxima da linguagem humana.
Interpretada: Executa o código linha por linha, sem precisar de compilação prévia.
Tipagem dinâmica: Em Python, não é necessário declarar o tipo das variáveis. O interpretador identifica automaticamente o tipo de acordo com o valor atribuído. Sendo necessário mudar um tipo para outro, utiliza-se a conversão explícita (casting).
Tipagem forte: Não junta tipos incompatíveis automaticamente (ex.: somar texto com número gera erro).
Multiparadigma: Aceita diferentes estilos de programação (orientada a objetos, funcional e procedural).

## Sintaxe básica - Estrutura e Indentação
- Execução: O código é lido de cima para baixo, linha por linha. Não usa ponto e vírgula (`;`) para encerrar comandos.
- Indentação: É o espaçamento no início da linha (a margem esquerda, geralmente feita com 4 espaços ou a tecla Tab).
Enquanto outras linguagens usam chaves { } para agrupar linhas de código, o Python usa apenas esse recuo para saber o que está dentro ou fora de uma estrutura (como uma condição, laço ou função).

Exemplo prático:
if True:
    print("Linha recuada: está DENTRO do if")

print("Linha sem recuo: está FORA do if")

## Variáveis - Criação e atribuição
Para criar uma variável, basta definir um nome e usar o operador `=` para atribuir um valor. O Python define o tipo automaticamente.
Uma variável pode ter seu valor e seu tipo alterados a qualquer momento atribuindo um novo valor a ela.

## Regras para nomes de variáveis
- Deve começar com uma letra ou sublinhado (`_`), nunca com número.
- Pode conter apenas letras, números e sublinhados (`a-z`, `0-9`, `_`).
- Diferencia maiúsculas de minúsculas (*case-sensitive*: `nome` é diferente de `Nome`).
- Não pode usar palavras reservadas da linguagem (como `if`, `for`, `class`).
- Convenção: usa-se o padrão `snake_case` (palavras em minúsculo separadas por `_`).

## Tipos de dados básicos
- int: Números inteiros, positivos ou negativos (ex.: `10`, `-5`).
- float: Números com casas decimais (ex.: `3.14`). Usa ponto `.`, nunca vírgula.
- str: Cadeia de caracteres (texto). Usa-se aspas simples ou duplas.
- bool: Representa apenas dois valores lógicos: `True` ou `False`. Letra inicial sempre maiúscula.
- type(): Função interna que retorna o tipo do dado ou da variável informada.

Exemplo prático do uso da função type():
print(type(idade))      # <class 'int'>

## Entrada de dados - input()
Função utilizada para capturar dados digitados pelo usuário no terminal. Todo valor retornado pela função input() é sempre uma string. 
Para utilizar o valor recebido em cálculos matemáticos ou lógicas numéricas, é necessário converter explicitamente o retorno com int() ou float().

## Saída de dados e f-strings
A função `print()` exibe informações no terminal. Para misturar texto fixo com variáveis, existem três formas principais:

- Separado por vírgula: Adiciona um espaço automaticamente entre os valores e aceita qualquer tipo de dado sem precisar converter.
- Concatenação (`+`): Junta apenas strings (exige conversão explícita com `str()` para números).
- f-strings: Adiciona a letra `f` antes das aspas e permite inserir variáveis ou expressões diretamente dentro de chaves `{}`.

Exemplo prático:
nome = "Marian"
idade = 20

1. Com vírgula: print("Nome:", nome, "- Idade:", idade) 
2. Com concatenação (precisa de str): print("Nome: " + nome + " - Idade: " + str(idade))
3. Com f-string: print(f"Nome: {nome} - Idade: {idade}") ou print(f"Idade ano que vem: {idade + 1}")

## Operadores aritméticos
Realizam operações matemáticas:
- `+` Adição
- `-` Subtração
- `*` Multiplicação
- `/` Divisão (retorna sempre `float`)
- `//` Divisão inteira (descarta a parte decimal)
- `%` Módulo (retorna o resto da divisão)
- `**` Potenciação (exponenciação)

## Operadores de atribuição
Definem ou atualizam o valor de uma variável:
- `=` Atribui um valor
- `+=` Soma e atribui
- `-=` Subtrai e atribui
- `*=` Multiplica e atribui
- `/=` Divide e atribui

## Operadores de comparação
Comparam dois valores e retornam sempre um booleano (`True` ou `False`):
- `==` Igual a
- `!=` Diferente de
- `>` Maior que
- `<` Menor que
- `>=` Maior ou igual a
- `<=` Menor ou igual a

## Operadores lógicos
Utilizados para combinar ou inverter condições:
- `and`: Retorna `True` se todas as condições forem verdadeiras.
- `or`: Retorna `True` se pelo menos uma condição for verdadeira.
- `not`: Inverte o valor lógico (`not True` vira `False`).

Exemplo prático com operadores de comparação:
print(10 >= 10)           # True
print(5 != 5)             # False

Exemplo prático com operadores lógicos:
idade = 18
tem_cnh = True
pode_dirigir = idade >= 18 and tem_cnh  # True

## Ordem de precedência
Quando vários operadores aparecem na mesma linha, o Python resolve na seguinte ordem:

1. `( )` Parênteses (prioridade máxima)
2. `**` Potenciação
3. `*`, `/`, `//`, `%` Multiplicação, divisões e resto (da esquerda para a direita)
4. `+`, `-` Adição e subtração (da esquerda para a direita)
5. `==`, `!=`, `>`, `<`, `>=`, `<=` Comparações
6. `not` Negação lógica
7. `and` Conjunção lógica
8. `or` Disjunção lógica
